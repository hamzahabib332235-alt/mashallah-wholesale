# MASHAALLAH WHOLESALE — source bundle

This archive contains the current editable Lovable/TanStack starter project and the uploaded project brief.

## Important status

The current application is still a starter page. The wholesale dashboard, billing, inventory, accounts, database-backed workflows, offline synchronization, and Windows desktop application described in the brief have not been implemented. This ZIP is source only; it is not a runnable wholesale management system or a Windows installer.

## Included

- Application source (`src/`), public files, and the existing Drizzle source folder
- Project manifests and configuration needed to install dependencies
- The original project brief

## Excluded

- Private environment variables and credentials (`.env`)
- Lovable workspace/project metadata and repository history
- Installed dependencies, caches, and build output

## Local development

Install Node.js and npm, extract this ZIP, run `npm install`, then `npm run dev`. Cloud-backed features require the appropriate Lovable Cloud project environment; credentials are intentionally not included.
